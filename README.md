## Course Information


### Recommended Textbooks
- Introduction to Computing Using Python: An Application Development Focus, 2nd Edition by Ljubomir Perkovic
- Practical Programming (2nd ed): An Introduction to Computer Science Using Python 3 by Paul Gries, Jennifer Campbell, Jason Montojo
- Think Python: How to Think Like a Computer Scientist by Allen Downey (free)

### Course Description
This course is designed to introduce students to the logic involved in the computing process. Students learn how to develop algorithms to describe solutions to a given problem and implement those solutions using a scripting language. The course emphasizes problem solving, programming logic, and practical use of a scripting language for computer-support related problems.

### Major Topics
1. Introduction to Computer Programs
2. Introduction to the Software Development Process
3. Using Data and Variables
4. Using Program Logic
5. Procedures
6. Linear Data Structures
